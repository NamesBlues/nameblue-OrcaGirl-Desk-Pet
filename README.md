# 虎鲸桌宠 🐋

一只浮在 Windows 桌面上的虎鲸娘。透明无边框、可以用鼠标拖着到处跑、会随机冒气泡说话。

素材来自你自己的画：Q 版虎鲸娘立绘 + 4 张手绘气泡。

![桌宠效果](docs/screenshot.png)

---

## 快速开始

**第一次使用**：双击 `install.bat`（建虚拟环境 + 装依赖 + 处理素材，PySide6 约 240MB，耐心等一会儿）

**日常启动**：双击 `run.bat`

**出问题了**：双击 `run_debug.bat`，会保留控制台窗口，能看到具体报错

---

## 怎么用

| 操作 | 效果 |
|---|---|
| 按住左键拖动 | 把桌宠拖到任意位置（松手自动记住坐标） |
| 单击桌宠 | 随机说一句话 |
| 右键托盘的小虎鲸图标 | 打开菜单：显示/隐藏、说句话、设置、开机自启、打开素材文件夹、退出 |

**想让它彻底消失**：右键托盘图标 → 退出。
直接按 Alt+F4 只会把它藏起来，托盘图标还在。

## 设置

右键托盘图标 → **设置…**，可以调：

- **桌宠大小** — 40% ~ 250%
- **气泡大小**
- **始终显示在其他窗口上方**
- **只在角色本体上响应鼠标** — 默认开启。透明的部分鼠标会穿透到桌面，
  不会出现「明明是一片空白却点不中桌面图标」的情况
- **启动时打招呼** — 启动后自动冒出「开始工作吧！！」
- **点击桌宠时说一句**
- **气泡停留时长**、**随机说话间隔**
- **开机自动启动** — 写进注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`

所有设置都存在 `config.json` 里，也可以直接编辑这个文件（改完重启程序生效）。
其中 `pet_position` 是拖拽后自动记录的坐标，设成 `null` 就会回到右下角。

## 换成你自己的素材

### 换角色立绘

用同名文件覆盖 `assets/orca_girl.png` 就行。建议用**带透明通道的 PNG**，裁掉四周留白。

程序以 **260px 高**为 `pet_scale = 1.0` 的基准，宽度按素材宽高比自动推算，
所以换任何比例的立绘都不会突然变得巨大或被压扁。

### 加新气泡 / 改台词

台词是画在图片上的，所以「加一句新台词」= 加一张新气泡图：

1. 画一张新气泡（透明底 PNG），放进 `assets/bubbles/`，例如 `bubble_5.png`
2. 重启桌宠 —— 它会自动加入随机轮播，不需要改任何代码

想调整哪句在什么时候出现，编辑 `config.json`：

```jsonc
{
  "startup_bubble": "bubble_1.png",   // 启动时说的那句
  "idle_exclude": ["bubble_1.png"]    // 随机说话时排除掉（专门留给启动问候）
}
```

### 处理新素材

如果你新画的图是**白底不透明**的，把它放到项目根目录，在 `tools/prepare_assets.py`
的 `JOBS` 列表里加一行，然后运行：

```bat
.venv\Scripts\python.exe tools\prepare_assets.py
```

脚本会自动抠白底（只抠与外界连通的白色，所以帽子、袜子这些被描边包围的白色不会被误伤）、
裁掉留白、缩放到合适尺寸，并在 `tools/preview.png` 生成一张洋红底的预览图供你检查边缘。

## 改代码之后

跑一下自检，几秒钟就能发现导入错误、素材缺失、尺寸异常、点击区域失效等问题
（它会建出所有窗口、模拟一次拖拽和一次单击，然后立刻退出）：

```bat
.venv\Scripts\python.exe tools\selftest.py
```

## 常见问题

**双击 run.bat 没反应？**
先用 `run_debug.bat` 跑一次看报错。多半是没执行过 `install.bat`。

**右下角任务栏里找不到小虎鲸图标？**
Windows 11 默认会把新出现的托盘图标收进 `^` 折叠区。
点开 `^` 把虎鲸图标拖到任务栏上固定住即可。程序本身运行是正常的。

**桌宠跑到屏幕外找不回来了？**
`config.json` 里把 `"pet_position"` 改成 `null`，重启就会回到右下角。

**点了桌宠没反应？**
检查设置里「只在角色本体上响应鼠标」——如果开着，必须点在角色身上才行，空白处会穿透。
单击要松手才会触发，拖拽超过 4 像素就会被判为拖动而不是点击。

**显示模糊？**
程序会按屏幕缩放比例重新采样素材（高分屏 200% 缩放下会加载 2 倍分辨率的位图），
正常情况下应该是清晰的。如果还是糊，把 `config.json` 里 `"pet_scale"` 调大试试。

**想再开一个？**
不支持。重复双击 `run.bat` 不会启动第二个实例，而是把已经在跑的那只叫到前台。
